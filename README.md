# クイヤゲーム改
[ザビャンのクイヤゲーム](https://www.thebyan.com/kuiyagame)の操作性が悪すぎてクソゲーを極めていたので勝手にリメイクしました。
このゲームは**完全無料・広告なし**です。
# 本家との改善点
・フルスクリーンデフォルト<br>
本家は開発者ツールをいじらないとフルスクリーンで遊べませんでしたがこれは標準でフルスクリーンです。<br>
・地形生成の見直し<br>
本家は地形生成が杜撰で復活直後にゲームオーバーになることがしょっちゅうありましたがここでは対策済みです。<br>
・ジャンプ力の強化<br>
ジャンプ力とそれに伴って進むスピードを上げています。難易度調整のためブロックはやや高くしました。<br>
・広告、アフィリエイトなし<br>
本家はアフィリエイトがありますがこのゲームは完全非営利のアフィリエイトなしです。<br>
・チート機能追加<br>
[拡張機能](https://github.com/KansaiActivist/kuiya-game-neo-cheat)を入れることでチートできます。<br>
・BGMなし<br>
気が散るBGMは一切ありません。
